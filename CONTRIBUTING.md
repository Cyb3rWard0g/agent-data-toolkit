# Contributing to Agent Data Toolkit

Thank you for your interest in contributing! This guide will help you get started.

---

## Development Setup

```bash
# Clone the repo
git clone https://github.com/Cyb3rWard0g/agent-data-toolkit.git
cd agent-data-toolkit

# Create a virtual environment with uv
uv venv .venv
source .venv/bin/activate

# Install in editable mode with dev + all connector extras
uv pip install -e ".[dev,all]"
```

## Running Tests

```bash
# Unit tests only (no database required)
pytest -q -m "not pg"

# PostgreSQL integration tests (requires a running PG instance)
export PG_DSN="postgresql://user:pass@localhost:5432/mydb"
pytest -q -m pg

# All tests
pytest -q
```

## Linting & Formatting

We use **Ruff** for linting, import sorting, and formatting:

```bash
# Lint
ruff check src tests

# Auto-fix lint issues
ruff check --fix src tests

# Format check
ruff format --check src tests

# Auto-format
ruff format src tests
```

## Code Style

- **Line length**: 100 characters
- **Target Python**: 3.11+
- **Type hints**: Use them everywhere. Use `from __future__ import annotations` for modern syntax.
- **Lazy imports**: Heavy dependencies (psycopg, pandas, pyarrow) are imported lazily so the package can be imported without extras installed.
- **Docstrings**: Use Google-style or NumPy-style docstrings on all public functions.

## Project Structure

```
src/agent_data_toolkit/
├── __init__.py              # Top-level version re-export
├── _version.py              # Auto-generated by setuptools_scm
└── postgresql/
    ├── __init__.py           # Lazy re-exports for the connector
    ├── client.py             # PostgresClient high-level façade
    ├── connection.py         # ConnectionInfo, ConnectionManager (pool, retry, SSL)
    ├── io.py                 # DataFrame ↔ Arrow ↔ Parquet helpers
    ├── queries.py            # query_rows, query_df, stream_rows, COPY, pipeline batch
    ├── schema.py             # Schema introspection (list_schemas/tables/columns, explain)
    └── sql.py                # Static SQL snippets
```

## Adding a New Connector

1. Create `src/agent_data_toolkit/<connector_name>/` with the same module pattern:
   - `connection.py` — config dataclass + connection manager
   - `queries.py` — query functions that accept the manager
   - `client.py` — high-level façade class
   - `__init__.py` — lazy re-exports
2. Add an extras group in `pyproject.toml` under `[project.optional-dependencies]`.
3. Add the extras name to the `all` bundle.
4. Add tests under `tests/<connector_name>/unit/` and `tests/<connector_name>/integration/`.
5. Add a pytest marker in `pyproject.toml` if integration tests need gating.

## Pull Request Checklist

- [ ] Code passes `ruff check` and `black --check`
- [ ] New/changed code has type hints
- [ ] Unit tests added or updated (run `pytest -q -m "not pg"`)
- [ ] Integration tests added if touching connector logic
- [ ] Docstrings on all new public functions / classes
- [ ] No hardcoded credentials or secrets

## Releasing

Releases are automated via GitHub Actions. To publish:

1. Ensure all tests pass on `main`.
2. Create and push an annotated tag:
   ```bash
   git tag -a v0.2.0 -m "Release 0.2.0"
   git push origin v0.2.0
   ```
3. The `publish.yml` workflow builds and uploads to PyPI via trusted publishing (OIDC).
